### Key learnings

1. **SvelteKit SPA routing**: `window.addEventListener('storage')` doesn't fire in same window — use a Svelte writable store subscribed in both layout and pages.
2. **Nuxt auto-env mapping**: `NUXT_PUBLIC_<KEY>` maps to `runtimeConfig.public.<camelCasedKey>` — key name must match exactly.
3. **Qwik reactivity**: `useStore` uses Proxy — deep mutations (direct property assignment, `splice`) are tracked; array replacement (`= array.map(...)`) is not reliably tracked in child components.
4. **Strict mode Playwright failures**: `locator.or().toBeVisible()` fails if BOTH locators match — only one feedback mechanism (nav count vs. text) should be visible at a time.
5. **Astro `-s` serve flag**: Serving Astro static output with `serve -s` (SPA mode) rewrites all routes to `index.html` — breaks multi-page Astro apps. Remove `-s` flag.
6. **CORS for CSR API calls**: Browser-side `fetch` to a different Docker service origin is blocked by CORS. Proxy through the framework's own server instead.
